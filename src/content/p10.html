1. Berapa biaya satu karyawan yang keluar?

Karyawan keluar berarti biaya rekrutmen, pelatihan, penurunan produktivitas, dan pengetahuan yang hilang. Riset praktik SDM sering memperkirakannya sebesar 0,5 hingga 2 kali gaji tahunan, tergantung jabatan. Gunakan kalkulator untuk memperkirakan nilai di organisasi Anda (asumsi, bukan angka pasti).

4. Etika & privasi data karyawan

Data HR sensitif. Dua praktik dasar: agregasi minimum (jangan tampilkan kelompok kurang dari 5 orang) dan akses berdasarkan peran (RLS, Pertemuan 13). Coba filter di bawah.

OutputP10_HRDashboard.pbix (1 halaman utama + catatan etika) dan 3 rekomendasi retensi berbasis data.

⬇ Dataset

320 karyawan fiktif (tanpa nama). Kolom: ID, Departemen, Gender, Usia, MasaKerjaTahun, Gaji, KehadiranPct, SkorKinerja, Status, AlasanKeluar.

📋 Langkah kerja

🧾 Measure HR

Headcount Total = COUNTROWS ( HR )
Karyawan Aktif = CALCULATE ( [Headcount Total], HR[Status] = "Aktif" )
Karyawan Keluar = CALCULATE ( [Headcount Total], HR[Status] = "Keluar" )
Attrition % = DIVIDE ( [Karyawan Keluar], [Headcount Total] )
Rata-rata Masa Kerja = AVERAGE ( HR[MasaKerjaTahun] )
Rata-rata Kehadiran = AVERAGE ( HR[KehadiranPct] ) / 100

Kelompok Usia (calculated column) =
SWITCH ( TRUE (),
  HR[Usia] < 25, "<25",
  HR[Usia] < 35, "25–34",
  HR[Usia] < 45, "35–44",
  "45+" )
