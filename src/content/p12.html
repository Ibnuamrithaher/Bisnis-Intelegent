1. Desember tinggi: bisnis tumbuh atau hanya musiman?

Penjualan Desember hampir selalu lebih tinggi dari November. Membandingkan bulan ke bulan (MoM) bisa menyesatkan oleh pola musiman. Membandingkan dengan bulan yang sama tahun lalu (YoY) memberi perbandingan yang setara (apple to apple).

2. Tabel kalender (Date Table)

Fungsi time intelligence membutuhkan tabel tanggal yang kontinu (tidak ada hari bolong), unik, dan mencakup seluruh rentang data. Pilih kolom, lihat kode DAX dan pratinjau tabel.

3. Bandingkan periode

4. Tren, rata-rata bergerak, dan musiman

Data mingguan sangat berfluktuasi. Rata-rata bergerak (moving average) menghaluskan derau agar tren terlihat. Geser jendela.

🧾 Pola DAX time intelligence

Dim_Tanggal =
ADDCOLUMNS (
  CALENDAR ( DATE ( 2023, 1, 1 ), DATE ( 2024, 12, 31 ) ),
  "Tahun", YEAR ( [Date] ),
  "BulanNo", MONTH ( [Date] ),
  "Bulan", FORMAT ( [Date], "MMM" ),
  "Kuartal", "Q" & QUARTER ( [Date] )
)

Revenue        = SUM ( Fakta[Pendapatan] )
Revenue LY     = CALCULATE ( [Revenue], SAMEPERIODLASTYEAR ( Dim_Tanggal[Date] ) )
YoY %          = DIVIDE ( [Revenue] - [Revenue LY], [Revenue LY] )
Revenue PM     = CALCULATE ( [Revenue], DATEADD ( Dim_Tanggal[Date], -1, MONTH ) )
MoM %          = DIVIDE ( [Revenue] - [Revenue PM], [Revenue PM] )
Revenue YTD    = TOTALYTD ( [Revenue], Dim_Tanggal[Date] )
Rata-rata 3 bln = AVERAGEX ( DATESINPERIOD ( Dim_Tanggal[Date], MAX ( Dim_Tanggal[Date] ), -3, MONTH ), [Revenue] )
