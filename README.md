# Bahan Ajar Interaktif Bisnis Intelegent

- Buka `dist/index.html` di browser (offline, tanpa instalasi). 14 file `pertemuan-XX.html`, tiap file mandiri.
- Tiap pertemuan: Ringkasan, Teori 45', Praktik 100', Kuis, Rangkuman & Tugas.
- Pemetaan RPS: pertemuan 1-7 = minggu 1-7, UTS minggu 8, pertemuan 8-14 = minggu 9-15, UAS minggu 16.
- Sumber: `src/` (base.css, lib.js, meta.js, content/pXX.html). Bangun ulang: `node build.js`. Uji: `node test/check.js`.
