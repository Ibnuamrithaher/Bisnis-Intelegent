Kamu analis BI baru di NusaMart

NusaMart punya tiga cabang. Tiap cabang menyimpan penjualan Semester 1 2026 dengan cara berbeda, dan angkanya selama ini dijumlahkan manual sehingga sering selisih.

  • Ekstrak tiga sumber dan buktikan jumlah barisnya cocok.
  • Gabungkan dengan Append Queries menjadi Penjualan_Gabungan.
  • Tampilkan semua nilai uang dalam Rupiah ala Indonesia.
  • Bangun dashboard satu halaman untuk Direktur Penjualan.

Format Rupiah dan bangun dashboard

Dokumentasi

Tulis laporan satu halaman

Dari 4800000.00 ke Rp 4.800.000

Format Indonesia memakai titik untuk ribuan dan koma untuk desimal, kebalikan format Inggris. Atur di tiga tempat.

CSV mentah4800000.00
Tampilan Excel$4,800,000.00
TargetRp 4.800.000,00

Atur locale file Power BI

File, Options and settings, Options, lalu Regional Settings. Pilih Indonesian (Indonesia) untuk Locale for import dan Model language.

Ini menentukan cara angka dibaca dan dipisah di seluruh model.

Format kolom dan measure

Pilih kolom, lalu Column tools, Format, Currency. Pilih Rp Indonesian (Indonesia). Jika tidak ada di daftar, pakai Custom.

"Rp" #,##0

Untuk kartu KPI, set Display units ke None agar tampil Rp 1.234.567.890, bukan 1,23 mlr.

Teks dinamis lewat DAX

Untuk judul dan label yang berubah mengikuti filter. Hasilnya teks, jadi jangan dipakai sebagai nilai sumbu grafik.

Total Pendapatan Teks =
"Rp " & FORMAT ( SUM ( Penjualan_Gabungan[Total_Penjualan] ), "#,0", "id-ID" )

Alternatif di Power Query:

"Rp " & Number.ToText([Total_Penjualan], "N0", "id-ID")

Benar saja belum cukup, dashboard harus enak dibaca

Tampilan dinilai sama berat dengan ketepatan data. Direktur harus paham dalam lima detik.

Wajib ada

  • 3 kartu KPI: Total Pendapatan, Jumlah Transaksi, Rata-rata Nilai Transaksi.
  • Diagram garis pendapatan per bulan.
  • Diagram batang pendapatan per cabang.
  • Pendapatan per kategori (batang, atau donut maksimal 4 irisan).
  • Slicer Cabang dan satu slicer pilihan.
  • Judul, periode, dan keterangan sumber data.

Aturan tampilan

  • Maksimal 4 warna, satu warna tetap untuk tiap cabang di semua visual.
  • Pilih tema dan latar sendiri, jangan bawaan polos.
  • Judul visual berupa insight, misalnya "Palembang menyumbang pendapatan tertinggi".
  • Semua angka uang berformat Rupiah Indonesia.
  • Jarak antar visual sama, tanpa efek 3D.

Sketsa tata letak

Hanya contoh susunan dengan bentuk grafik ilustrasi, bukan data asli. Boleh dimodifikasi asal informasi terpenting tetap di kiri atas.

Kendala yang sering muncul

Total pendapatan Jawa jauh lebih besar dari cabang lain

Hampir pasti locale harga CSV salah, sehingga titik terbaca sebagai pemisah ribuan. Ulangi Change Type, Using Locale, English (United States).

Ada kolom Harga Satuan dan Harga_Satuan sekaligus, sebagian isinya null

Nama kolom tidak seragam saat Append. Rename kolom di query sumber, lalu ulangi Append.

Query Excel berisi teks aneh, bukan data transaksi

Kamu memilih sheet yang salah. Buka ulang Navigator dan pilih sheet Penjualan.

Power BI tidak bisa terhubung ke MySQL

Pastikan MySQL berjalan, skrip .sql sudah dieksekusi, dan MySQL Connector/NET terpasang. Jika tetap gagal, minta file alternatif ke dosen.

Rupiah tampil di kartu tapi tidak di sumbu grafik

Sumbu butuh angka, bukan teks. Format kolom atau measure numeriknya lewat Column tools, bukan hasil FORMAT().
